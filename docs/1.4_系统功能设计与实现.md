## 1.4.1 系统总体架构

```
┌─────────────────────────────────────────────────────────┐
│                      系统架构图                           │
├─────────────────────────────────────────────────────────┤
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐      │
│  │   菜单模块   │  │ 游戏核心模块 │  │ 玩家操作模块 │      │
│  │  (Menu)     │  │  (Game)     │  │  (Input)    │      │
│  └─────────────┘  └─────────────┘  └─────────────┘      │
│           ┌──────────────────────────────┐              │
│           │        共享数据层             │              │
│           │   board / current_player     │              │
│           └──────────────────────────────┘              │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐      │
│  │  AI决策模块  │  │   渲染模块   │  │   音效模块   │      │
│  │  (AI)       │  │  (Render)   │  │  (Audio)    │      │

```

### 1.4.2.2 游戏核心模块 (Game Core Module)

**模块职责**：管理棋盘状态、落子逻辑和胜负判定，是系统的数据中枢。

**功能列表**：

| 功能 | 描述 |
|------|------|
| 棋盘初始化 | 创建15×15空棋盘 |
| 落子管理 | 验证并执行落子操作 |
| 玩家切换 | 黑白棋交替 |
| 胜负判定 | 检测四方向五子连珠 |
| 候选点生成 | 缩小AI搜索范围 |

**核心数据结构**：

```python
# 棋盘常量
BOARD_SIZE = 15           # 15×15标准棋盘
EMPTY = 0                 # 空位
BLACK_STONE = 1           # 黑棋
WHITE_STONE = 2           # 白棋

# 游戏状态
self.board = [[0]*15 for _ in range(15)]  # 棋盘状态
self.current_player = BLACK_STONE        # 当前玩家
self.game_over = False                   # 游戏结束标志
self.winner = None                       # 获胜者
self.move_history = []                   # 落子历史记录
```

**关键方法**：

```python
def place_stone(i, j, player=None):
    """落子并检查胜负"""
    if self.board[i][j] != EMPTY or self.game_over:
        return False
    self.board[i][j] = player
    self.move_history.append((i, j, player))
    if self.check_winner(i, j, player):
        self.game_over = True
        self.winner = player
    else:
        self.current_player = 3 - player  # 切换玩家
    return True

def check_winner(i, j, player):
    """胜负判定：检查四个方向的连续棋子"""
    directions = [(0,1), (1,0), (1,1), (1,-1)]  # 横/竖/斜/反斜
    for dx, dy in directions:
        count = 1
        # 正向检查
        x, y = i+dx, j+dy
        while 0<=x<BOARD_SIZE and 0<=y<BOARD_SIZE and self.board[x][y]==player:
            count += 1; x+=dx; y+=dy
        # 反向检查
        x, y = i-dx, j-dy
        while 0<=x<BOARD_SIZE and 0<=y<BOARD_SIZE and self.board[x][y]==player:
            count += 1; x-=dx; y-=dy
        if count >= 5:
            return True
    return False
```

**模块职责**：处理用户输入，实现人机交互。

**功能列表**：

| 功能 | 描述 |

| 菜单交互 | 按钮悬停、点击响应 |

| 悔棋功能 | PVP撤销1步，PVE撤销2步 |

**坐标转换算法**：

```python
def screen_to_board(x, y):
    """屏幕坐标 → 棋盘坐标"""
    board_y = y - INFO_HEIGHT
    i = round((board_y - MARGIN) / CELL_SIZE)
    j = round((x - MARGIN) / CELL_SIZE)
    if 0 <= i < BOARD_SIZE and 0 <= j < BOARD_SIZE:
        return i, j
    return None, None

def undo_move(self, steps=1):
    """悔棋操作"""
    if self.mode == 'pve':
        steps = min(2, len(self.move_history))  # PVE撤销2步
    for _ in range(steps):
        i, j, player = self.move_history.pop()
        self.board[i][j] = EMPTY
        self.current_player = player
```

**事件处理流程**：

```
鼠标点击 → 坐标转换 → 碰撞检测 → 执行操作
    │
    ├→ 按钮区域 → 执行按钮对应功能
    └→ 棋盘区域 → 执行落子逻辑
```

### 1.4.2.4 AI决策模块 (AI Module)

**模块职责**：实现AI落子决策，支持两种算法策略。

#### 4.4.1 Minimax + Alpha-Beta 剪枝

**算法流程**：

```
┌─────────────────────────────────────────┐
│         get_best_move_minimax()          │
├─────────────────────────────────────────┤
│ 1. 获取候选点 (get_candidate_moves)      │
│ 2. 紧急防守检测                          │
│    ├→ 对手即将获胜 → 直接防守            │
│    └→ 对手活三/冲四 → 优先防守           │
│ 3. 进攻排序                              │
│    └→ 按评估分值排序候选点               │
│ 4. Minimax搜索 (最多15个候选点)           │
│ 5. 返回最高分值对应的落子                 │
└─────────────────────────────────────────┘
```

**评估函数设计**：

| 棋型 | 分值 | 说明 |
|------|------|------|
| FIVE | 100,000 | 五连 |
| ALIVE_FOUR | 10,000 | 活四 |
| SLEEP_FOUR | 5,000 | 冲四 |
| ALIVE_THREE | 5,000 | 活三 |
| SLEEP_THREE | 200 | 眠三 |
| ALIVE_TWO | 100 | 活二 |
| SLEEP_TWO | 10 | 眠二 |

**候选点优化**：

```python
def get_candidate_moves():
    """获取有价值的落子候选点"""
    candidates = set()
    for i in range(BOARD_SIZE):
        for j in range(BOARD_SIZE):
            if self.board[i][j] != EMPTY:
                # 扩展已有棋子周围2格范围
                for di in range(-2, 3):
                    for dj in range(-2, 3):
                        ni, nj = i+di, j+dj
                        if 0<=ni<BOARD_SIZE and 0<=nj<BOARD_SIZE:
                            if self.board[ni][nj] == EMPTY:
                                candidates.add((ni, nj))
    return list(candidates)
```

### 1.4.2.6 音效模块 (Audio Module)

**模块职责**：实现程序化音效生成，无需外部音频文件。

**功能列表**：

| 功能 | 描述 |
|------|------|
| 音效生成 | 使用正弦波+指数衰减生成 |
| 落子音效 | 800Hz, 0.1秒 |
| 胜利音效 | 523Hz (C5), 0.3秒 |
| 静音控制 | 支持开关切换 |

**音频生成算法**：

```python
def generate_sound(frequency, duration, volume=0.5):
    sample_rate = 44100
    n_samples = int(duration * sample_rate)
    t = np.linspace(0, duration, n_samples, False)
    
    # 生成正弦波
    wave = np.sin(2 * np.pi * frequency * t)
    
    # 指数衰减（模拟真实音效）
    wave = wave * np.exp(-t / (duration * 0.3))
    
    # 归一化到16位音频范围
    wave = (wave * volume * 32767).astype(np.int16)
    
    # 转换为立体声
    stereo_wave = np.column_stack((wave, wave))
    
    return pygame.mixer.Sound(buffer=stereo_wave.tobytes())
```

## 1.4.4 本章小结

本章详细介绍了五子棋游戏系统的功能设计与实现方案。系统采用模块化架构，包含菜单模块、游戏核心模块、玩家操作模块、AI决策模块、渲染模块和音效模块六个核心功能模块。

各模块职责明确，相互协作：菜单模块提供游戏入口和模式选择；游戏核心模块管理棋盘数据和游戏逻辑；玩家操作模块处理用户交互；AI决策模块实现智能落子（支持Minimax算法和深度学习两种策略）；渲染模块负责所有图形绘制；音效模块提供程序化音频反馈。
